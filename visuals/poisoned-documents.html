Try the real model
Open the running app at localhost:3000. In Poisoned document lab, select each mode and click Run demo question. Expand the context beneath the answer to see exactly what reached the model.
The live endpoint uses the same aggregate() as normal chat with gpt-4o-mini for this demo; normal chat uses gpt-6-sol. It inserts local synthetic fixtures in place of retrieval. The model writes the answer; the app never inserts the banana phrase into its output.
What this demonstrates
The attack lives in a document, not the user question or system prompt. Fake role labels inside a note do not grant authority, but the model may follow them anyway.
Build the defense in class. This demo passes retrieved documents straight to the model. A live model may ignore the attack; marker presence alone does not prove it obeyed.
